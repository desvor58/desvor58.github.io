Philosophy

Three decisions, and everything else follows

micro is small on purpose. Every feature it has was kept because the code generator could make it cheap.

01

Flat

A program is a plain list of instructions, and instructions are grouped into functions. No blocks, no scopes, no implicit control flow — you write exactly what should happen, step by step.

02

No AST

The parser turns your text into a list of instruction structs. Or you generate that list yourself when micro is used as a library. There is no tree to allocate, walk or free.

03

Fast to compile

The goal is compile speed over execution speed. A straight pipeline with an arena and no node allocations is what gets there — micro reaches a callable function in about 12 µs.

The language

Linear code, written in prefix

Expressions are prefix (Polish) form, so every operand of an operation is in a known place — the shape the code generator wants. Comments are wrapped in backslashes.

+ 5 * 3 2→5 + (3 * 2)
* 5 + 3 2→5 * (3 + 2)
$ p→*p

Same function, same branch, same two calls. What is gone is the expression tree: every result is named, so the code generator can give it a machine register. 

fun add
    i32 a
    i32 b
    ret i32
start
    ret + a b;
end

fun main
    ret i32
start
    set i32 sum;
    call sum add 10 5;   \ one call, one set \
    ret sum;
end

Functions look like labels

Arguments, an optional ret type, then the body between start and end.

Calls are explicit

call <result register> <function> <args…>. Use _ to throw the result away.

Order is checked

The callee has to be defined before the call, the way an assembler wants it.

fun entry
    ret i32
start
    set i32 a 5 {lifetime:1};
    set i32 b a;       \ still alive here \
    set i32 a 9;       \ the name is free again \
    set i32 c + b a;
    ret c;
end

Virtual registers

Eight base types: i8 u8 i16 u16 i32 u32 f32 ptr. A register keeps its type for life.

Six machine registers

A value gets a machine register while it is alive and the stack when they run out. Lifetime hints shorten the stay.

Pointers

Put $ in front of the name to read or write through the address it holds.

fun f
    i32 n
    ret i32
start
    if n : non_zero;     \ jumps when n != 0 \
    if ! <= n 1 : big;  \ jumps when n > 1 \
    ret 0;
big:
    goto tail;
non_zero:
    ret 2;
tail:
    ret 1;
end

Labels and jumps

name: and goto name; are the only way to build a loop.

Conditional jumps

if <expr> : <label> is a conditional goto. Prefix with ! to test for false.

No surprises

After the jump target the code continues normally, and a missing label is a compile error.

tramp vm_add
    i32 a
    i32 b
    ret i32
end

fun call_add
    i32 a
    i32 b
    ret i32
start
    set i32 res;
    call res vm_add a b;
    ret res;
end

Trampolines

Declare a function your host program implements with tramp instead of fun, and give the code generator a map from that name to a handler.

One handler, many shapes

The handler gets a frame with the argument words and their count, so a single trampoline can dispatch calls of different arity.

Why it exists

To reach an interpreted function or a VM entry point that the compiler cannot see.

Architecture

One straight line, two front doors

Every stage after the instruction generator is the library. A host program can start at any of them.

Code generator

Write it in the shape it folds into one instruction

Two patterns are recognised while an expression is lowered, and only used when every operand already lives in a machine register. You never ask for it — you just write the address the way it should be computed. 

fun folds
    ret i32
start
    set i32 base 16;
    set i32 index 3;
    set i32 addr + base * index 4;  \ one lea \
    set i32 next + index 1;         \ one inc \
    set i32 tail + addr 4;          \ one lea \
    ret tail;
end

The rule

You never ask for the fold. The expression has the right shape, so the code generator finds the pattern while it lowers.

Displacement is part of the match

A literal added to the scaled term is folded into the instruction, and the shortest of the three encodings wins.

Anything else still works

A scale of 3, or an operand that already spilled to the frame, simply falls back to the plain imul and add sequence.

the same function, as printed by microc -Pa

Measurements

Where the time actually goes

Fibonacci, GCD, checksum, bubble sort and matrix multiply, compiled through the public API of each backend. Median over the workloads.

micro emits x86-32; the local LLVM and MIR helpers run on x86-64 with their native ABIs, and MIR has no i386 backend in this checkout. These ratios are honest about compile speed and explicitly not an ISA-independent code-quality claim. Use comp/benchmark_i386.py for the like-for-like native run.

Status

An unstable MVP, honestly labelled

The whole pipeline works and is tested. The language and the code generator are still moving.

Working

  • Lexer
  • Instruction builder
  • i386 code generator with lea code selection
  • Assembly peephole optimizer
  • IR optimizer: inlining of small calls, -Oi
  • 191 unit tests over lexer, instructions and backend
  • Library API — the compiler itself is built on it
  • Trampolines, in source and through an API map
  • Embed as a library, compile at runtime, map the bytes, call it

Not there yet

  • Object file output — the result is a raw binary
  • Backends other than i386
  • f32 arithmetic
  • Bitwise operators
  • Dead code removal after inlining

Get started

Clone, make, compile

A plain Makefile, gcc or clang, and a 32-bit toolchain. Nothing else to install.

build & test
git clone https://github.com/desvor58/micro-lang
cd micro-lang
make            # build microc
make test       # 191 tests, debug and release-fast
make MODE=debug # the slow, readable build
make examples   # compile, mmap and call real code
use microc
microc [flags] <input file>

-P t|i|a   print tokens / instructions / asm
-S r|l|i|a stop after a stage
-N a       skip a stage
-O i       run the inlining pass
-o <file>   output name, a.out by default

./bin/microc -Oi -Pa -o fib.bin fib.micro
